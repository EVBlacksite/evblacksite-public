# EV Blacksite — Feedback & Bug Reports

This repo isn't the code. It's where you tell me when something on
[evblacksite.com](https://evblacksite.com) is broken, missing, or could be better.

## How to file something

Go to the [Issues tab](../../issues/new/choose) and pick a template:

- **Bug report** — something's broken or wrong
- **Feature request** — something's missing

Screenshots help a lot. Drag them straight into the form.

## What happens next

Every issue lands on the EV Blacksite Roadmap. I triage things in
batches — usually within a few days. You'll get a notification on your issue
when it moves to "In Progress" and when it ships.

For anything sensitive (account issues, billing, suspected security stuff)
don't open a public issue — email support@evblacksite.com instead.
